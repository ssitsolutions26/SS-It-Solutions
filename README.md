## 🛠️ Features & Products

### 1. Solar Quotation & Billing (Solar ERP)
A comprehensive ERP featuring:
- **Company Settings:** Fully customizable dynamic settings for branding.
- **GST Quotation Generator:** Professional invoice generation.
- **Payment Tracking:** Easy tracking for incoming and outgoing payments.
- **Inventory & Stock Management:** Keep track of your solar panels, batteries, and accessories.
- **Automated PDF Export:** Create and download invoices on the fly.

### 2. Bill Master Pro
- Barcode-ready retail POS
- Complete GST invoicing platform
- Quick sales reports and customer master

### 3. Smart Pharma ERP
- Medicine inventory tracking
- Batch management and expiry alerts

## 💻 Running Locally

To run the project on your local machine:
1. Clone the repository: `git clone https://github.com/ssitsolutions26/SS-It-Solutions.git`
2. Open the directory: `cd SS-It-Solutions`
3. Serve locally using `npx`:
   ```bash
   npx serve -l 8080
   ```
4. Open `http://localhost:8080` in your browser.
