# Security Guidelines

## Reporting a Vulnerability
If you discover a security vulnerability within this project, please send an e-mail to our security team. All security vulnerabilities will be promptly addressed.

## Implemented Security Measures
- Forms submit via AJAX to prevent page hijacking.
- No sensitive API keys are exposed in the frontend.

## Planned Improvements (Phase 9)
- Implementation of Content Security Policy (CSP).
- Strict Transport Security (HSTS) headers via host.
- XSS prevention auditing.
